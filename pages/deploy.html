انشر CyberAr على الإنترنت

3 طرق مجانية 100% لنشر موقعك والحصول على رابط مباشر. كل طريقة مع شرح خطوة بخطوة.

1

GitHub Pages (موصى به)

مجاني · HTTPS تلقائي · يدعم Domain مخصص

الخطوة 1: أنشئ مستودع GitHub

  1. روح github.com/new
  2. اسم المستودع: iraqrahomi.github.io
  3. اختر Public
  4. اضغط Create repository

الخطوة 2: ارفع الملفات

افتح PowerShell في مجلد المشروع ونفّذ:

# Initialize git

git init

git add .

git commit -m "🚀 Launch CyberAr v2.0"

git branch -M main

# Connect to GitHub

git remote add origin https://github.com/iraqrahomi/iraqrahomi.github.io.git

git push -u origin main

الخطوة 3: فعّل GitHub Pages

  1. روح **Settings** في المستودع
  2. اختر **Pages** من القائمة الجانبية
  3. تحت **Source**: اختر **GitHub Actions**
  4. انتظر 2-3 دقائق
  5. موقعك الآن لايف على: https://iraqrahomi.github.io

✅ مميزات: HTTPS مجاني · PWA جاهز · SEO كامل · صفر تكلفة

2

Netlify (سحب وإفلات)

مجاني · بدون Git · نشر خلال ثوانٍ

  1. روح app.netlify.com/drop
  2. اسحب مجلد المشروع كامل وأفلته في الصفحة
  3. انتظر 30 ثانية
  4. موقعك لايف على: https://random-name.netlify.app
  5. يمكنك تغيير الاسم إلى cyberar.netlify.app
3

Vercel (الأسرع)

مجاني · CDN عالمي · أداء خرافي

  1. روح vercel.com/new
  2. سجّل دخول بحساب GitHub
  3. اختر المستودع iraqrahomi.github.io
  4. اضغط Deploy
  5. خلال 60 ثانية موقعك لايف على: cyberar.vercel.app

ربط Domain مخصص (cyberar.com)

1. اشترِ النطاق

من Namecheap أو GoDaddy أو Cloudflare Registrar. ابحث عن cyberar.com

2. أضف DNS Records

في إعدادات DNS للنطاق:

# For apex domain (cyberar.com)

A @ 185.199.108.153

A @ 185.199.109.153

A @ 185.199.110.153

A @ 185.199.111.153

# For www subdomain

CNAME www iraqrahomi.github.io

3. فعّل Domain في GitHub

  1. Settings → Pages → Custom domain
  2. اكتب: cyberar.com
  3. فعّل Enforce HTTPS
  4. انتظر 24 ساعة للتفعيل الكامل

Checklist قبل النشر

  • اختبار الموقع محلياً (http://localhost:8080)
  • كل الصفحات تعمل بدون 404
  • SEO meta tags كاملة (title, description, OG)
  • الصور مضغوطة (myphoto.jpg < 50KB)
  • Favicon + Logo موجودين
  • PWA manifest جاهز
  • sitemap.xml محدّث
  • robots.txt صحيح
  • اختبار Lighthouse على Chrome DevTools
  • اختبار على الجوال الحقيقي
