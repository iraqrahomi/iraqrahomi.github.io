Burp Suite - دليل الإتقان

الأداة الأشمل لاختبار اختراق تطبيقات الويب. من Proxy إلى Scanner، احترفها خطوة بخطوة.

؟ ما هي Burp Suite؟

Burp Suite هي منصة متكاملة لاختبار أمان تطبيقات الويب، من تطوير PortSwigger (نفس مطوري PortSwigger Academy المجاني). تتكون من عدة أدوات تعمل معاً:

  • Proxy: يعترض ويعالج HTTP/HTTPS
  • Repeater: يعيد إرسال الطلبات مع تعديل
  • Intruder: أتمتة brute-force/fuzzing
  • Scanner: فحص الثغرات آلياً (Pro فقط)
  • Decoder/Comparer: معالجة البيانات

📥 التثبيت والإعداد

  1. حمّل من portswigger.net/burp
  2. اختر Community Edition (مجاني) أو Pro (3500$/سنة)
  3. ثبّت Java JRE إذا لم يكن موجوداً
  4. شغّل Burp، روح لـ Proxy → Options
  5. افتراضياً يسمع على 127.0.0.1:8080

🌐 إعداد المتصفح (FoxyProxy)

الخطوة 1: ثبّت FoxyProxy

إضافة Firefox/Chrome لتبديل الـ Proxy بسرعة.

الخطوة 2: أنشئ Proxy جديد

Title: BurpSuite

Proxy Type: HTTP

Proxy IP: 127.0.0.1

Port: 8080

الخطوة 3: شهادة CA

زُر http://burp/cert وحمّل شهادة Burp CA. استوردها في المتصفح.

⚡ الأدوات الأساسية

1. Proxy

يعترض كل حركة المرور بين المتصفح والسيرفر. شغل "Intercept is on" لترى كل request.

GET /api/users HTTP/1.1

Host: target.com

Cookie: session=abc123

Authorization: Bearer xyz

2. Repeater

تعدل request وترسله عدة مرات لرؤية response. مثالي لاختبار:

  • • تعديل parameters (price, role, id)
  • • تجربة payloads مختلفة لـ SQLi/XSS
  • • تكرار الطلب بعد logout لاختبار session

3. Intruder

أتمتة brute-force و fuzzing. 4 أنواع attacks:

  • Sniper: payload واحد على position واحد
  • Battering Ram: نفس الـ payload على كل positions
  • Pitchfork: payload sets متعددة بالتوازي
  • Cluster Bomb: كل combination ممكن

4. Scanner (Pro فقط)

يفحص التطبيق آلياً ويطلع بثغرات مُرتبة حسب الخطورة. مجاني؟ استخدم OWASP ZAP كبديل.

🎯 مثال عملي: اكتشاف IDOR

السيناريو:

  1. سجّل دخول في التطبيق
  2. روح لصفحة profile، شوف الـ request في Burp Proxy
  3. لاحظ الـ URL: /api/users/1001/profile
  4. ابعث للـ Repeater
  5. غيّر 1001 إلى 1002
  6. إذا رجع بيانات user آخر = IDOR موجود!
