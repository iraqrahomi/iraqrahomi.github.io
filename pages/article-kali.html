Kali Linux - دليل التثبيت الكامل

ثبّت Kali Linux في VMware وأعد بيئة اختبار اختراق احترافية. خطوة بخطوة مع نصائح الأمان.

؟ ما هي Kali Linux؟

Kali Linux هي توزيعة Debian-based مصممة خصيصاً لـ اختبار الاختراق الأخلاقي. تحتوي على أكثر من 600 أداة أمان مثبتة مسبقاً.

Nmap, Wireshark

Burp Suite, ZAP

Metasploit, sqlmap

📥 تحميل Kali Linux

  1. روح kali.org/get-kali
  2. اختر إصدار Installer Images (مو Live - تحتاج تثبيت كامل)
  3. للـ VM اختر Kali Linux 64-Bit (Installer)
  4. حمّل ملف ISO (~4GB)
  5. تحقق من الـ SHA256 للتأكد إن الملف ما تالف

💡 نصيحة: لا تستخدم Kali على جهازك الأساسي كـ primary OS. استخدمها في Virtual Machine لعزل آمن.

💻 إعداد VMware Workstation

1. إنشاء VM جديد

  • File → New Virtual Machine
  • اختر Typical (recommended)
  • اختر Installer disc image file (ISO)
  • اختر ملف Kali ISO اللي حملته
  • اختر Linux → Debian 11/12 64-bit
  • اسم: Kali Linux
  • Disk: 50GB على الأقل (الأفضل 100GB)
  • Customize Hardware:
    • RAM: 4GB كحد أدنى (8GB أفضل)
    • CPUs: 2 على الأقل
    • Network: NAT

2. تثبيت Kali

  1. شغّل VM
  2. اختر Graphical Install
  3. اختر اللغة: English (الواجهة الرسومية أسهل)
  4. Keyboard: Arabic أو English
  5. Hostname: kali
  6. Domain name: اتركه فارغ
  7. كلمة مرور root: اختر كلمة قوية!
  8. Disk partitioning: Guided - use entire disk
  9. انتظر التثبيت (10-15 دقيقة)
  10. Reboot

🔧 ما بعد التثبيت (5 أشياء فوراً)

1. تحديث النظام

sudo apt update && sudo apt upgrade -y

sudo apt dist-upgrade -y

2. تثبيت VMware Tools

sudo apt install open-vm-tools-desktop -y

sudo reboot

هذا يحسّن: نسخ/لصق، دقة الشاشة، مشاركة الملفات.

3. إنشاء user غير root (للأمان)

sudo adduser pentester

sudo usermod -aG sudo pentester

4. تثبيت أدوات إضافية

sudo apt install -y gedit git curl wget vim

sudo apt install -y gobuster ffuf burpsuite

5. تفعيل snapshots

في VMware: VM → Snapshot → Take Snapshot

لو خربطت النظام، ترجع للـ snapshot بنقرة واحدة.

HackTheBox Pwnbox

VM في المتصفح مع كل الأدوات مثبتة.

⚠️ نصائح أمان مهمة

  • • لا تستخدم Kali للتصفح اليومي - فيه أدوات هجوم
  • • لا تخزن بيانات حقيقية على Kali
  • • استخدم VPN على الـ Host network
  • • حدّث باستمرار - الثغرات في Kali = ثغرات لك
  • • اعمل snapshot نظيف بعد التثبيت مباشرة
  • • اقرأ /usr/share/doc/* لتعلم كل أداة
